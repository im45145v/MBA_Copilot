# MBA Copilot
### Leverage GitHub Copilot to solve real business problems with AI

> Learn how to use GitHub Copilot beyond code generation by analysing business data, building executive dashboards and creating AI-powered workflows.

---

## 🚀 Overview

Welcome to **MBA Copilot**.

In this workshop, you'll use **GitHub Copilot** to tackle a realistic business challenge using a real retail dataset.

Instead of writing everything manually, you'll collaborate with GitHub Copilot to:

- 📊 Analyse business performance
- 📈 Discover trends and insights
- 🧹 Clean and prepare data
- 🎯 Generate executive recommendations
- 🎨 Build a modern business dashboard
- 🤖 Work with AI Agents, Skills, Prompt Files and Chat Modes
- 🚀 Explore how AI can accelerate decision-making

This workshop is designed for MBA students, business analysts and professionals who want to use AI effectively—not just for writing code, but for solving business problems.

---

# 🏢 Business Scenario

You have just joined **Nova Retail** as a Business Analyst.

The executive leadership team has asked you to answer several important questions before tomorrow's strategy meeting.

Some of the questions include:

- Why is profit decreasing despite increasing sales?
- Which regions are performing the best?
- Which products generate the highest profit?
- Are discounts affecting profitability?
- Which customer segments deserve more investment?
- How should the business prioritise future growth?

You'll use GitHub Copilot to answer these questions using the provided dataset.

# 🛠 Recommended Workflow

For each exercise:

1. Understand the business problem.
2. Ask Copilot to create a plan.
3. Review the proposed solution.
4. Refine prompts where necessary.
5. Use specialised Chat Modes or Agents.
6. Validate the results.
7. Present recommendations.

Think of Copilot as a collaborator—not an autopilot.

---

# 💡 Tips

- Start with the business problem, not the technology.
- Ask specific questions.
- Build iteratively.
- Validate AI-generated output.
- Use different Chat Modes for different perspectives.
- Experiment with Prompt Files and Skills.
- Compare multiple approaches before making decisions.
